## Give every route a clear way home.

**Waymark is Steward's selected identity.** One continuous route forms an S;
the two endpoints keep the mark grounded in real connections. The voice is warm,
precise, and quietly capable.

The lowercase wordmark, rounded routing mark, and warm orange accent carry the
same idea: native tools, explicit ownership, and careful changes.

## Logo download

[Download the Waymark SVG](../../brand/waymark.svg).

The same canonical SVG supplies the website mark, browser favicon, and public
download. It stays crisp at small sizes and adapts to light/dark browser themes.
The website mark follows the selected site theme.

## Usage

- Keep the mark's proportions and rounded endpoints intact.
- Leave clear space around it rather than placing it against another icon.
- Use a single contrasting ink color; the website uses its text color.
- Use the lowercase **steward** wordmark alongside the mark where space permits.
