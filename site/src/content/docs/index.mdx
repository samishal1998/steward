## Observe first. Plan with evidence.

A hostname alone does not tell you who owns a route, whether it is loaded, or how it should be changed. Steward keeps native identities, reported status, and incomplete coverage visible.

<CardGrid>
  <Card title="Read what the proxy reports." icon="magnifier">

  </Card>
  <Card title="Keep uncertainty in view." icon="information">
    Disabled routes, unfamiliar matchers, and partial inventories stay visible. An inaccessible API never becomes a reassuring empty list.
  </Card>

## Start with one command.

Linux or macOS, Intel or ARM64. The installer verifies release checksums and places only the CLI in your local bin directory.

```sh
curl -fsSL https://samishal1998.github.io/steward/install.sh | sh
```

```sh
~/.local/bin/steward --help
~/.local/bin/steward tui
```

There is no stable release yet. Install the current documented alpha, then connect an existing proxy. The CLI installer does not enable APIs or start services.
